Plotwright privacy policy

This policy covers Plotwright Publisher, the private tool that uploads videos to the Plotwright YouTube channel, and the Plotwright pages on this site. It is short because the tool does very little with personal data: it has one user, and that user is its owner.

Last updated 21 October 2026 · plotwright.hq@gmail.com

Who runs this

Plotwright Publisher and the Plotwright channel are run by Aditya Vora, Pune, India (the "owner"). Contact: plotwright.hq@gmail.com.

What Plotwright Publisher is

A command-line program that runs on the owner's own computer. It uploads finished videos to the owner's YouTube channel, sets their titles, descriptions, thumbnails and scheduled publish times, replies to comments on the owner's videos, and reads the channel's own analytics. It is not distributed, has no sign-up, and is not available to anyone other than the owner.

Google user data it accesses

The tool asks the owner's Google account for permission to manage the owner's YouTube channel (the YouTube Data API scopes for uploading and managing videos and comments) and to read that channel's analytics (the YouTube Analytics read-only scope). Through those permissions it accesses:

  • video metadata and upload status for the owner's own videos,
  • comments posted on the owner's own videos, so the owner can reply,
  • aggregate analytics for the owner's own channel: views, watch time, subscribers and similar figures.

It does not access any other Google account, any other channel, contacts, email, or anything outside the Plotwright channel.

How that data is used

Only to publish and manage the owner's own videos and to report the channel's own performance back to the owner. Aggregate analytics are kept in local files on the owner's computer so that trends can be compared week to week. Comment text is read only to compose a reply and is kept in a local log alongside that reply.

Where it is stored and who can see it

The OAuth tokens that grant access, and every file the tool writes, live on the owner's own computer. Nothing is sent to any server other than Google's APIs. No data obtained through Google APIs is sold, shared with third parties, used for advertising, or used to train machine-learning models. No one other than the owner has access to it.

Limited Use

Plotwright Publisher's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local analytics and comment logs are kept for as long as the channel runs, because the week-to-week comparison depends on them. The owner can delete them at any time by deleting the files. Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops the tool from reaching the account.

Viewers of the channel

Plotwright Publisher holds no personal data about people who watch the channel. Viewer data is handled by YouTube under Google's privacy policy. If you comment on a Plotwright video, your public comment may be read by the tool so that the owner can reply to it, and nothing else is done with it.

This website

The Plotwright pages on adityavora.in set no cookies and ask for no personal information. The site uses Vercel Web Analytics, which counts page views without cookies or personal identifiers.

Changes

If anything above changes, this page is updated and the date at the top moves. Questions: plotwright.hq@gmail.com.
